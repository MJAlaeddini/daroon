# Tests

| Where                     | What it checks                                                                                                                                                                                                                                             | Run                                        |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| `packages/shared/test`    | Jalali calendar against the browser's own calendar (1990–2060), story prompt and validation, schemas                                                                                                                                                       | `pnpm --filter @daroon/shared test`        |
| `apps/api/test`           | Sign-in, sessions, CSRF, rate limits, two-device sync, stories, account deletion; against real PostgreSQL                                                                                                                                                  | `pnpm --filter @daroon/api test`           |
| `apps/web/test`           | The web vocabulary matches what the server accepts                                                                                                                                                                                                         | `pnpm --filter @daroon/web test`           |
| `apps/web/e2e/acceptance` | Acceptance: at four sizes and both themes, the sculpture's position is recorded every 35 ms; text must not fall on it, it must not jump, and two pages must not stay stacked. Also layout, touch targets, contrast, text size, reduced motion and keyboard | `pnpm test:e2e`                            |
| `apps/web/e2e/flows`      | All 24 guided paths, saving with a note, undoing a delete, sign-in validation, offline start                                                                                                                                                               | same                                       |
| `apps/web/e2e/sync`       | Two devices through the real API: an entry travels without its note, and so does its deletion                                                                                                                                                              | `E2E_API=1 DATABASE_URL=... pnpm test:e2e` |

The API tests need PostgreSQL. The default is `postgres://daroon:daroon@localhost:5433/daroon_test`; override it with `TEST_DATABASE_URL`. CI runs all of these on every push.
