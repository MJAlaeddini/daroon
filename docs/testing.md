# تست‌ها

| کجا                       | چی رو می‌سنجه                                                                                                                                                                                                    | اجرا                                       |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| `packages/shared/test`    | تقویم جلالی در برابر تقویم خود مرورگر (۱۹۹۰ تا ۲۰۶۰)، پرامپت و اعتبارسنجی داستان، اسکیماها                                                                                                                       | `pnpm --filter @daroon/shared test`        |
| `apps/api/test`           | ورود، نشست، CSRF، محدودیت درخواست، همگام‌سازی دو دستگاه، داستان‌ها، حذف حساب؛ روی PostgreSQL واقعی                                                                                                               | `pnpm --filter @daroon/api test`           |
| `apps/web/test`           | سازگاری واژگان وب با سرور                                                                                                                                                                                        | `pnpm --filter @daroon/web test`           |
| `apps/web/e2e/acceptance` | تست پذیرش: در چهار اندازه و دو تم، هر ۳۵ میلی‌ثانیه جای شکل ثبت می‌شه؛ متن نباید روی شکل بیفته، شکل نباید بپره، دو صفحه نباید روی هم بمونن؛ به‌علاوه چیدمان، هدف لمسی، کنتراست، اندازه‌ی متن، کاهش حرکت و کیبورد | `pnpm test:e2e`                            |
| `apps/web/e2e/parity`     | اپ و پروتوتایپ اصلی صفحه‌به‌صفحه با هم مقایسه می‌شن (حداکثر ۱٪ اختلاف پیکسلی)                                                                                                                                    | همون                                       |
| `apps/web/e2e/flows`      | ۲۴ مسیر راهنما، ثبت با یادداشت، برگردوندن حذف، اعتبارسنجی ورود، اجرای آفلاین                                                                                                                                     | همون                                       |
| `apps/web/e2e/sync`       | دو دستگاه با API واقعی: ردپا بدون یادداشت منتقل می‌شه و حذفش هم                                                                                                                                                  | `E2E_API=1 DATABASE_URL=... pnpm test:e2e` |

برای تست‌های API یک PostgreSQL لازمه. پیش‌فرض `postgres://daroon:daroon@localhost:5433/daroon_test` است و با `TEST_DATABASE_URL` عوض می‌شه. در CI همه‌ی این‌ها روی هر push اجرا می‌شن.
